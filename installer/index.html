Web Installer & Serial Configurator

Install, recover, configure and diagnose DCCExpressHub directly from Chrome or Edge.

This tool requires desktop Chrome or Microsoft Edge with Web Serial support. GitHub Pages HTTPS is supported directly.

Firmware installer

Download the correct merged firmware for your Hub hardware, then select that BIN file below. The selected file is flashed directly from your computer; the installer does not download firmware itself.

LOCAL BIN INSTALLER
Before installation: download the correct *-merged.bin firmware from the DCCExpressHub Releases page. Do not flash firmware built for another Hub hardware target.
Official firmware filenames:
M5Stack Basic: DCCExpressHub-M5Stack-Basic-DCCEX-v<version>-merged.bin
ESP32 DevKit: DCCExpressHub-ESP32-DevKit-DCCEX-v<version>-merged.bin
USB driver: the Hub must appear in Windows as a serial / COM port. If no COM port appears after connecting the device, install the USB-UART driver used by your board (typically CH340/CH341 or Silicon Labs CP210x) and make sure the USB cable supports data transfer.
The selected file is installed as a complete merged DCCExpressHub image at 0x000000. A full install may erase existing Hub configuration and stored layout data. Create a backup before flashing if needed.

Select the downloaded DCCExpressHub merged BIN file.

Web Serial is not supported by this browser. Use desktop Chrome or Edge.

The installer asks you to choose the Hub USB serial device. There is no separate COM-port selector on this page.

Serial configuration

Connect to the firmware at 115200 baud. If the Hub is rebooting or running an older firmware without the configuration protocol, the serial connection remains open in recovery mode instead of disconnecting.

Hub network

Network settings are stored in NVS and take effect after Hub restart.

Hub hostname: the default hostname is dccexpresshub — without hyphens and without .local. The default browser address is therefore http://dccexpresshub.local.

EX-CSB1 connection

These values are stored in NVS and applied immediately.

Connection test —
Tests hostname resolution, TCP connection and a real DCC-EX <#> reply.
Reply: —
EX-CSB1 / DCC-EX address: enter the complete address used to reach the command station. For the DCC-EX mDNS hostname use dccex.local (including .local), or enter its IP address.
